# Real Estate AI Daily — Podcast Feed

Public RSS feed for the daily AI news podcast.

**Feed URL:** https://tagryantoos-commits.github.io/real-estate-ai-daily-podcast/feed.xml
**Cover:** https://tagryantoos-commits.github.io/real-estate-ai-daily-podcast/cover.png
**Site:** https://tagryantoos-commits.github.io/real-estate-ai-daily-podcast/

Episodes are auto-generated daily by a Hermes cron job at 7 AM Mountain and pushed here. MP3s are hosted on catbox.moe (referenced from the feed); only metadata + cover live in this repo.

## Updating

The render script automatically commits and pushes after each new episode.
